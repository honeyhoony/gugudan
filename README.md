# 한판 — 온라인 체육대회 화면 게임

대구본부 에너지효율부 온라인 체육대회 등을 위해, 프로젝터(큰 화면)로 진행하고 참가자는 휴대폰으로 접속하는 행사 게임입니다.

## 게임

- **O/X 퀴즈** — 진행자가 문제 출제, 휴대폰에서 O/X 선택, 화면에서 집계·정답 공개
- **랜덤 뽑기** — 접속한 참가자 중 한 명을 극적으로 추첨
- **순발력** — “지금!”이 뜨면 가장 빨리 누른 사람 점수 획득

## 사용 방법

1. 진행자 PC/노트북에서 사이트 접속 → **방 만들기**
2. 프로젝터에 진행 화면을 띄우고 QR 또는 방 코드를 보여주기
3. 참가자는 휴대폰으로 QR 스캔(또는 코드 입력) 후 닉네임 입장
4. 상단에서 O/X · 랜덤 · 순발력 모드 전환

## 로컬 실행

```bash
npm install
npm run dev
```

브라우저에서 `http://127.0.0.1:3000` 접속.

같은 Wi‑Fi의 휴대폰에서 쓰려면 개발 PC의 LAN IP로 접속하거나, Cursor Apps로 배포하세요.
